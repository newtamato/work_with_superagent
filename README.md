# work_with_superagent

Sandbox repository for dsh-superagent: open an issue or comment mentioning the agent account to request work.

## Requesting work

Anyone can request a change by opening an issue or commenting on an existing one and mentioning the agent account (`@JolieHou`). Describe the small change you want: name the file or behavior to change and the result you expect. The agent replies on the issue, makes the change on a branch, and opens a pull request for review.

## Status

This repository is a sandbox for dsh-superagent.
